# Student Service System

## Описание проекта
Информационная система для обработки обращений студентов.

## Цель проекта
Упростить приём, регистрацию и обработку обращений.

## Структура проекта
- docs — документация;
- models — модели и диаграммы;
- src — исходный код;
- tests — тесты.

## Правила работы
Изменения кода проходят проверку через Pull Request.
Запрещено хранить пароли и личные данные студентов в репозитории.
